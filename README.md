# 인생계획

일정 달력 + 텐미닛 플래너 PWA. 폰 홈에 얹으면 앱처럼 돈다.

- **월 달력** — 일정만 색 막대로 (연애·재영·취업·은화·예약·업무·기타). 날짜를 누르면 팝업으로 기입
- **주간계획** — 이번 주 7줄. 줄을 누르면 그 날 텐미닛 플래너로
- **텐미닛 플래너** — 하루 한 장. 한 칸 10분 타임테이블(06시~다음날 05:50) + 할 일 + 집중도 + 내장 타이머
- 오프라인에서도 돌고, 기기 사이는 **비공개 저장소의 `plan-data.json`** 으로 오간다

이 저장소는 **빌드 산출물만** 둔다 — 일정 데이터는 여기 없다. 소스와 빌더는
`J_0/planner/` (`build_planner.py`, `src/`) 에 있고, 고칠 때는 거기서 고쳐 다시 뽑는다.

```powershell
py planner/build_planner.py     # → planner/site/
```

## 폰에 넣기

1. GitHub Pages 주소를 폰 브라우저에서 열어 홈 화면에 추가
2. 설정에서 GitHub 토큰 붙이기 (데이터 저장소의 Contents 읽기·쓰기만 주는 fine-grained PAT).
   주소 끝에 `#t=토큰` 을 붙여 한 번 열어도 된다
